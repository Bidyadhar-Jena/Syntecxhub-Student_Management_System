# Student Management System (CLI)

A simple Command-Line Interface (CLI) based Student Management System built using Python.  
This project demonstrates basic Object-Oriented Programming (OOP) concepts and file handling using JSON.

## Features

- Add new student records
- View all students
- Update existing student details
- Delete student records
- Unique Student ID validation
- Persistent data storage using JSON file

## Technologies Used

- Python
- JSON (for data storage)
- OOP Concepts (Classes & Methods)
